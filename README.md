day_counter

Counts the number of days between two dates.
Usage

python3 day_counter.py <year1> <month1> <day1> <year2> <month2> <day2>
Example: `python3 day_counter.py 2024 1 1 2025 1 1` prints `366`.
Files

`is_leap_year.py` - is a year a leap year?
`days_in_month.py` - how many days are in a month
`is_valid_date.py` - is a date real?
`day_counter.py` - the main program
